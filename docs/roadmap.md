# Project Roadmap

## Vision

Clash of Clans Analytics Bot начинался как личный инструмент для автоматизации управления кланом и получения уведомлений о важных игровых событиях.

Долгосрочная цель проекта — превратить систему в полноценную платформу для управления кланами Clash of Clans, которая помогает лидерам принимать решения на основе исторических данных, аналитики и автоматизированных отчетов.

Проект развивается поэтапно, постепенно переходя от простого уведомления о событиях к интеллектуальному помощнику для управления кланом.

---

# Current State

На текущем этапе система поддерживает:

* автоматическую синхронизацию данных через Clash of Clans API;
* хранение исторических данных в SQLite;
* отслеживание состава клана;
* хранение истории войн;
* хранение данных CWL;
* хранение данных рейдов;
* автоматическую отправку отчетов в Telegram;
* защиту от повторной отправки уведомлений.

Система обслуживает один клан и одного получателя уведомлений.

---

# Phase 1 — Core Platform

Статус: В процессе завершения

Цель этапа:

Создать стабильную архитектурную основу для дальнейшего развития проекта.

Основные задачи:

* завершение базовой архитектуры проекта;
* завершение слоя репозиториев;
* завершение миграционной системы;
* улучшение структуры сервисов;
* повышение надежности синхронизации;
* улучшение логирования;
* контейнеризация приложения через Docker.

Результат:

Стабильная платформа для хранения и обработки игровых данных.

---

# Phase 2 — Event-Driven Architecture & Multi-Clan Support

Статус: Следующий приоритет

Цель этапа:

Подготовить проект к масштабированию и коммерческому использованию.

---

## Event System

Внедрение доменных событий как основного механизма взаимодействия между подсистемами.

Планируемые возможности:

* централизованный Event Dispatcher;
* независимые обработчики событий;
* снижение связности компонентов;
* упрощение добавления новых функций;
* подготовка к аналитическим сервисам.

Примеры событий:

* PlayerJoinedClan;
* PlayerLeftClan;
* WarEnded;
* RaidWeekendEnded;
* CWLDayEnded.

---

## Multi-Clan Support

Поддержка нескольких кланов внутри одного экземпляра приложения.

Планируемые возможности:

* несколько кланов;
* несколько Telegram-чатов;
* независимые подписки;
* отдельные настройки для каждого клана;
* масштабирование количества обслуживаемых кланов.

Результат:

Переход от личного инструмента к полноценному сервису.

---

# Phase 3 — Advanced Reporting & Analytics

Статус: Planned

Цель этапа:

Превратить систему из набора уведомлений в аналитическую платформу.

---

## Advanced Reports

Развитие существующих отчетов.

Планируемые возможности:

* подробная статистика войн;
* статистика CWL;
* статистика рейдов;
* анализ состава клана;
* сравнительные отчеты;
* долгосрочная аналитика.

---

## Player Analytics

Планируемые возможности:

* рейтинг активности игроков;
* история участия в войнах;
* история участия в CWL;
* история участия в рейдах;
* эффективность атак;
* эффективность защиты;
* анализ пропусков атак.

---

## Clan Analytics

Планируемые возможности:

* развитие клана во времени;
* динамика состава;
* активность участников;
* статистика пожертвований;
* исторические показатели эффективности.

Результат:

Лидеры клана получают не только уведомления, но и инструменты для принятия решений.

---

# Phase 4 — Interactive Telegram Platform

Статус: Planned

Цель этапа:

Сделать Telegram полноценным пользовательским интерфейсом системы.

---

## Telegram Commands

Планируемые возможности:

* просмотр статистики игрока;
* просмотр статистики клана;
* просмотр истории войн;
* просмотр статистики CWL;
* просмотр статистики рейдов;
* получение рейтингов игроков;
* поиск исторических данных.

Примеры команд:

/player

/war

/cwl

/raids

/ranking

/inactive

---

## Configuration Management

Планируемые возможности:

* настройка уведомлений через Telegram;
* управление подписками;
* включение и отключение отдельных отчетов;
* управление несколькими кланами.

Результат:

Большинство задач по управлению системой выполняется напрямую через Telegram.

---

# Phase 5 — Clan Management Assistant

Статус: Long-Term Vision

Цель этапа:

Создать интеллектуального помощника для управления кланом.

---

## Automated Recommendations

Планируемые возможности:

* выявление неактивных игроков;
* рекомендации по исключению участников;
* рекомендации по составу CWL;
* выявление систематических нарушений;
* автоматический анализ эффективности игроков.

---

## Performance Scoring

Планируемые возможности:

* общий рейтинг игрока;
* рейтинг активности;
* рейтинг участия в событиях;
* рейтинг эффективности атак;
* рейтинг дисциплины.

---

## Management Insights

Планируемые возможности:

* автоматические выводы на основе статистики;
* предупреждения о проблемах состава;
* выявление тенденций активности;
* рекомендации для лидеров клана.

Результат:

Система помогает принимать управленческие решения на основе накопленных данных.

---

# Commercialization

Одной из целей проекта является создание коммерчески жизнеспособного сервиса.

Планируемая модель:

* подписка на сервис;
* поддержка нескольких кланов;
* различные уровни доступа;
* расширенные аналитические возможности для подписчиков.

Первые коммерческие версии могут предоставлять:

* автоматические отчеты;
* историческую аналитику;
* рейтинги игроков;
* расширенную статистику войн, CWL и рейдов.

Даже небольшое количество платных пользователей позволит подтвердить востребованность продукта и определить дальнейшее направление развития.

---

# Future Opportunities

После достижения основных целей возможно развитие в дополнительных направлениях.

Потенциальные возможности:

* веб-панель аналитики;
* экспорт отчетов в CSV и Excel;
* REST API;
* внешние интеграции;
* мобильное приложение;
* облачная версия сервиса;
* поддержка других игровых сообществ.

Данные направления не являются приоритетными и будут рассматриваться после завершения основных этапов развития.

---

# Long-Term Goal

Долгосрочная цель проекта — создать платформу, которая позволит лидерам кланов получать полную информацию о составе, активности и эффективности участников без необходимости ручного контроля.

Система должна стать инструментом управления кланом, объединяющим сбор данных, аналитику, автоматические отчеты и поддержку принятия решений в едином решении.
