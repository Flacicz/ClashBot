# Telegram-интеграция

## Назначение

Telegram в проекте используется в двух независимых режимах:

* `NotificationService` отправляет отчеты и напоминания подписанным чатам и темам;
* `TelegramBotService` принимает сообщения и callback-запросы от пользователей, показывает интерактивное меню
  видео-гайдов и управляет Telegram-подписками кланов.

Интерактивное меню не изменяет состав клана или другие игровые данные SQLite. Команды `/link` и `/unlink` изменяют
Telegram-подписки и состояние отслеживания клана.

## Конфигурация

Параметры находятся в секции `bot` файла `config.json`:

```json
{
  "bot": {
    "telegram_token": "<TELEGRAM_BOT_TOKEN>",
    "attack_guides_path": "resources/telegram/attack_guides.json"
  }
}
```

`attack_guides_path` разрешается относительно текущего рабочего каталога процесса. В Docker используется путь
`/app/resources/telegram/attack_guides.json`.

Каталог загружается во время запуска. Ошибка открытия файла, некорректный JSON или неправильный тип поля приводят к
ошибке запуска приложения.

## Пользовательский сценарий

Команда `/start` отправляет главное меню. Дальше пользователь последовательно выбирает:

1. ратушу TH7–TH18;
2. стратегию;
3. видео-гайд.

После выбора бот отправляет название и ссылку на YouTube. Inline-кнопки позволяют вернуться к списку гайдов,
стратегий или в главное меню.

Кнопка `❓ Помощь` показывает основные команды подключения и отключения кланов, а также правила доступа для групп.

### Подключение клана

Чтобы подключить клан, отправьте в нужном Telegram-чате команду:

```text
/link #CLAN_TAG
```

Например:

```text
/link #2PPLQ
```

Команда `/link` привязывает Telegram-назначение к клану:

* в личном чате создаётся подписка аудитории `management`;
* в группе или супергруппе создаётся подписка аудитории `players`;
* если команда отправлена в форумной теме, сохраняется её `message_thread_id` и уведомления будут приходить в эту тему.
* если клана ещё нет в таблице `clans`, создаётся минимальная запись с именем `Pending synchronization`;
* если отслеживание клана было отключено, оно включается снова.

Добавление клана, сохранение Telegram-чата и создание подписки выполняются в одной транзакции. После подключения клан
попадёт в следующий цикл синхронизации, где Clash of Clans API заполнит остальные сведения.

В личном чате команда доступна пользователю этого чата. В группе или супергруппе подключать кланы могут только
администраторы и создатель группы. Чтобы проверка прав работала, боту необходимо предоставить права администратора
в группе.

### Просмотр и отключение

Кнопка `📋 Мои кланы` показывает кланы, подключённые к текущему чату, теме и аудитории.

Команда `/unlink #CLAN_TAG` или кнопка `❌ Отключить клан` удаляет подписку текущего Telegram-назначения. Если у чата
больше не осталось подписок, запись чата удаляется. Если у клана больше нет подписок вообще, его отслеживание
отключается, но исторические данные клана сохраняются в базе.

Для групп и супергрупп команда и кнопка отключения доступны только администраторам и создателю группы. В личном чате
отключить клан может пользователь этого чата.

Примеры команд:

```text
/link #2PPLQ
/link 2pplq
/unlink #2PPLQ
```

Повторное выполнение `/link` безопасно: существующая подписка не дублируется.

Поддерживаемые callback-команды:

```text
menu:start
help:main
clans:link
clans:list
clans:unlink
clans:unlink:<clan_tag>
guides:townhalls
guides:townhall:<town_hall>
guides:strategy:<town_hall>:<army_id>
guides:guide:<town_hall>:<guide_id>
```

`parseCallbackData` выполняет только структурный разбор строки: выделяет команду из первых двух частей и сохраняет
остальные части как аргументы. `TelegramBotService` дополнительно проверяет количество аргументов, диапазон ратуши и
наличие стратегии или гайда в каталоге.

## Формат каталога гайдов

Корневой JSON-объект содержит массив `guides`:

```json
{
  "version": 1,
  "guides": [
    {
      "id": "th7_zap_dragons_azilee",
      "army_id": "zap_dragons",
      "army_title": "Зап-драконы",
      "variant_id": "classic",
      "variant_title": "Классический вариант",
      "title": "Название видео",
      "town_halls": [7],
      "youtube_url": "https://www.youtube.com/watch?v=...",
      "sort_order": 10,
      "enabled": true
    }
  ]
}
```

Обязательные поля записи: `id`, `army_id`, `variant_id`, `variant_title`, `title`, `town_halls`, `youtube_url`.

Необязательные поля:

* `army_title` — по умолчанию используется `army_id`;
* `sort_order` — по умолчанию `0`;
* `enabled` — по умолчанию `true`.

Гайды сортируются по `sort_order` со стабильным порядком одинаковых значений. Отключенные записи не показываются.
Пустой массив `town_halls` означает, что гайд доступен для любой ратуши.

## Реализация

`TelegramApiClient` выполняет вызовы Telegram Bot API для отправки, редактирования и получения сообщений, проверки
участника группы через `getChatMember`, а также для подтверждения callback-запросов. `TelegramBotService` получает
обновления через long polling в отдельном потоке.

Чистая логика вынесена в отдельные компоненты:

* `TelegramCallbackData` — разбор callback-данных и контекста;
* `TelegramKeyboards` — построение JSON inline-клавиатур;
* `TelegramValidation` — проверка номера ратуши;
* `AttackGuideCatalog` — загрузка, фильтрация и поиск гайдов.

Проверка доступа к управлению кланами выполняется в `TelegramBotService`: для групп сервис запрашивает статус автора
команды или callback-запроса через Telegram API и разрешает действие только администраторам и создателю группы.

Для отправки отчетов и интерактивного меню используется один Telegram bot token, но эти два потока обработки логически
разделены.

## Тестирование

Unit-тестами покрыты чистые компоненты Telegram:

* разбор корректных и некорректных callback-данных;
* разбор callback-контекста Telegram JSON;
* структура всех inline-клавиатур;
* диапазон и некорректные значения ратуши;
* загрузка, сортировка, фильтрация и поиск записей каталога, включая ошибки структуры и типов JSON.

Тесты запускаются через стандартный `ClashBotTests` и CTest, как описано в основном [`README.md`](../README.md).
