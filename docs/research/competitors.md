# Исследование аналогов ClashBot (Telegram, Discord, Web/Mobile)

Дата: 2026-11-24

## 1. Главные выводы по рынку

1. **Ниша серьёзного Telegram-менеджмента кланов почти свободна.** Основная конкуренция сосредоточена в **Discord** (`ClashPerk`, `ClashKing`) и на **Web/Mobile** (`ClanWarden`, `ClashSpot`, `Clash of Stats`). В Telegram преобладают либо простые open-source скрипты, либо единичные закрытые боты (`@joraclashbot`, `@xs_coc_bot`).
2. **Уникальный срез ClashBot — фокус на дисциплину и разделение аудиторий.** Большинство ботов отправляют все события в один чат или требуют ручной настройки множества каналов Discord. ClashBot изначально разделяет **аудитории** (`players` и `management`), поддерживает **Telegram-назначения** с форумными топиками (`chat_id + message_thread_id`), а также строит отчёты по **нарушениям** и надёжности состава.
3. **Высокий бесплатный стандарт.** Поскольку официальный Clash of Clans API бесплатен, крупные платформы (`ClashKing`, `ClanWarden`, `ClashSpot`, `ClansHQ`) отдают базовую и даже глубокую аналитику бесплатно. Прямой пейволл только за «статистику войны» плохо работает — пользователи платят за **облачный хостинг без возни с VPS/IP-привязкой CoC API**, **масштаб (много кланов/чатов)**, **скорость обновлений**, **брендирование** и **инструменты, повышающие винрейт**.

> **Примечания по рынку:**
> - В поиске по Telegram/СНГ также встречается **CoCoBot** (`cocobot.top` / `clanua.com`, бесплатный лимитированный тариф / €10 lifetime), однако это бот-автофармер для ПК/Android (компьютерное зрение, эмуляторы), нарушающий правила Supercell — он не относится к клановому API-мониторингу.
> - Веб-трекер **ChocolateClash** официально закрыт разработчиком (`kuilin`), что подчёркивает риск выгорания при долгом содержании бесплатных сервисов без устойчивой экономики.
> - **ClashTrack** (`clash-track.com`) активен и специализируется преимущественно на калькуляторах прокачки и планировании прогресса игрока, а также на ведении баз/координации.

## 3. Разбор по сегментам и полезные практики

### Telegram (прямая ниша ClashBot)
- **Публичные боты (`@joraclashbot`, `@xs_coc_bot`)** закрывают базовый спрос в СНГ: уведомления о КВ/CWL/рейдах, напоминания об атаках, отчёты/таблицы или бронь целей.
- **Open-source проекты (`clashogram`, `chapeullah/coc-clan-bot`, `infoeneseren/coc-telegram-bot-replit`)** — сравнительно простые боты без транзакционной очереди доставки, развитой аналитики нарушений или управления аудиториями.
- **Вывод:** в Telegram нет доминирующего современного open-source + SaaS продукта уровня `ClashPerk` или `ClanWarden`.

### Discord (бенчмарк UX и монетизации)
- **Self-updating messages (`ClashPerk`):** вместо потока отдельных сообщений о каждой атаке одно сообщение динамически обновляется по ходу войны. В Telegram реализуется через `editMessageText`.
- **«Last Seen» и тонкая настройка логов (`ClashPerk`):** оценка последней активности игрока (атаки, донат, смена статуса войны) и маршрутизация типов событий по отдельным каналам/веткам.
- **Бронирование баз (`Sidekick`, `Warmatch`):** резервирование целей на КВ с таймером истечения брони, чтобы не возникало конфликтов и затянутых ожиданий.

### Web и Mobile (бенчмарк управленческой аналитики)
- **`ClanWarden`** — главный ориентир для `management`-функционала:
  - экран **«Today»** (список срочных задач прямо сейчас: кто не атаковал, у кого истекает время, кто накопил страйки);
  - **система страйков (Strikes)** и **чёрный список («Do Not Accept»)** с приватными заметками руководства;
  - **планировщик состава CWL** на основе надёжности игроков и оценки шансов;
- **`ClashSpot`** — учёт **реального вклада в Столицу внутри конкретного клана** (в игре виден только общий lifetime-вклад за всё время).

## 4. Позиционирование ClashBot: преимущества и пробелы

### Сильные стороны ClashBot уже сейчас
- Чёткое разделение **аудиторий** (`players` / `management`) — игроки не видят токсичных управленческих разборов, а руководство получает концентрированную картину по дисциплине.
- Поддержка **форумных тем Telegram** (`chat_id + message_thread_id`).
- Готовая аналитика динамики (`Better / Worse / Similar` со взвешиванием размеров войн) и сегментации надёжности состава (*Риск / Требуют внимания / Стабильные*).
- Встроенное интерактивное меню видео-гайдов по TH7–TH18.
- Надёжная архитектура доставки: SQLite WAL, транзакционный outbox (`domain_events` → `domain_event_destinations` → `notifications`), backoff и обработка `retry_after`.

### Главные функциональные пробелы относительно лидеров
1. **Нет интерактивных команд по текущему состоянию** (`/war`, `/raid`, `/player`, «кто не отбился сейчас»).
2. **Нет бронирования целей на КВ** (war caller с таймерами).
3. **Не настраиваются критерии нарушений, категории уведомлений, часовой пояс и интервал опроса** (сейчас фиксированный цикл 15 минут и UTC+3 в ряде мест).
4. **Нет страйков / чёрного списка и помощника составления ростера CWL.**
5. **Ограничения длинных списков в Telegram** (нет разбиения сообщений > 4096 символов, экспорта в CSV/таблицы или веб-панели для 30–50 участников).

## 5. Гипотезы монетизации для гибридной модели (Open-Source Core + Cloud/SaaS)

При развитии ClashBot по модели **открытое self-hosted ядро + облачный публичный Telegram-бот (SaaS)**:

1. **Главный драйвер ценности облака — снятие инфраструктурного барьера CoC API.** Официальный API требует статический IP; большинство лидеров клана не готовы поднимать VPS, Docker и SSH-туннель ради бота. Публичный бот с подключением в один шаг (`/link #TAG`) сам по себе решает главную боль.
2. **Бесплатный уровень (для роста и конкуренции с `@joraclashbot` и `ClashKing`):**
   - 1 клан;
   - базовые уведомления КВ / CWL / рейдов и напоминания;
   - каталог гайдов TH7–TH18 и базовые команды просмотра.
3. **За что реально готовы платить (`$2–$10/мес` или эквивалент / Telegram Stars):**
   - **Масштаб и альянсы (модель `ClashPerk` Bronze/Silver/Gold):** несколько кланов, сводки по семье кланов / академке.
   - **Быстрый live-цикл и интерактивные сводки:** опрос каждые 2–5 минут в активной войне и авто-обновляемое сообщение хода КВ.
   - **Глубокая управленческая аналитика и веб-панель:** долгий архив, страйки/чёрный список, планировщик состава CWL, экспорт в CSV / Google Таблицы (модель `League Utils`).
   - **Кастомизация правил:** гибкие правила **нарушений** (зеркало ±1, исключения), отключение отдельных типов отчётов, свой часовой пояс.
   - **White-label / свой брендированный бот (модель `ClashPerk` Bot Personalizer за `$10/мес`):** запуск личного токена `@BotFather` клиента на облачной инфраструктуре сервиса.
   - **Комьюнити-доход:** донаты (Patreon / Boosty / Telegram Stars) + Supercell Creator Code на масштабе.
