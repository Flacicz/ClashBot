# ClashBot

ClashBot — автономный сервис, который получает данные из официального API Clash of Clans и помогает отслеживать ключевые показатели активности клана и его участников.

Сервис предназначен для глав и соруководителей кланов. Он упрощает контроль активности игроков, позволяет наблюдать за их прогрессом и помогает принимать решения по управлению кланом. ClashBot уже поддерживает одновременное отслеживание нескольких кланов и отправку отчётов в несколько Telegram-чатов, хотя сейчас используется только для одного клана.

ClashBot регулярно собирает информацию о кланах и сохраняет её в базе данных. На основе полученных данных сервис формирует удобные отчёты и отправляет их руководителям кланов через Telegram. Это автоматизирует выявление нарушений и избавляет глав и соруководителей от необходимости вручную проверять активность каждого участника.

> Проект находится в активной разработке. Сервис уже собирает большую часть доступной информации о кланах, однако в отчётах пока используется только часть этих данных.

## Основные возможности

- **Войны кланов** — отчёт о результате войны, пропущенных атаках и атаках не по зеркалу.
- **Рейды столицы клана** — результаты рейдовых выходных и список участников, которые не выполнили необходимое количество атак.
- **Лига войн кланов** — результаты всех семи раундов, пропущенные атаки и атаки не по зеркалу в каждом раунде.
- **Изменение ролей** — уведомления о повышении и понижении участников внутри клана.
- **Изменение состава** — уведомления о вступивших в клан и покинувших его игроках.
- **Хранение истории** — сохранение полученной информации в базе данных для последующего анализа.
- **Telegram-отчёты** — автоматическая отправка собранной информации в удобном для чтения формате.

## Как работает ClashBot

1. При запуске ClashBot получает из базы данных список отслеживаемых кланов.
2. Сервис последовательно собирает через API Clash of Clans сведения о составе кланов, войнах, Лиге войн кланов и рейдовых выходных. После завершения полного цикла ClashBot делает паузу на 30 минут, а затем запускает следующую синхронизацию.
3. Полученные данные преобразуются, сравниваются с уже имеющейся информацией и сохраняются в базе данных SQLite.
4. При обнаружении значимых изменений или завершении игровых событий сервис формирует отчёты. В них отражаются результаты событий и типовые нарушения активности: пропущенные атаки, использование только одной из двух атак, атаки не по зеркалу и невыполненные рейды.
5. Готовые отчёты отправляются во все Telegram-чаты, подписанные на соответствующий клан. ClashBot учитывает уже отправленные уведомления и не отправляет одно и то же событие повторно.

## Технологии

- **C++23** — основной язык и стандарт разработки.
- **CMake** — сборка проекта и управление зависимостями.
- **SQLite** — хранение актуальных и исторических данных.
- **CPR и libcurl** — выполнение HTTP-запросов.
- **nlohmann/json** — обработка данных в формате JSON.
- **spdlog** — логирование работы приложения.
- **Docker** — сборка и запуск сервиса в изолированном окружении на базе Ubuntu 24.04.
- **Стандартная библиотека C++** — многопоточность и синхронизация фоновых процессов.

### Внешние сервисы

- **Clash of Clans API** — получение игровых данных.
- **Telegram Bot API** — отправка отчётов и уведомлений.

## Установка и запуск

ClashBot можно запускать локально на Windows для разработки или разворачивать в Docker на Linux-сервере.

### Требования

Для работы ClashBot потребуются:

- токен официального API Clash of Clans;
- Telegram-бот и его токен;
- Linux-сервер со статическим публичным IP;
- тег отслеживаемого клана;
- идентификатор Telegram-чата.

Для локальной разработки на Windows также потребуются:

- Git;
- CMake;
- компилятор с поддержкой C++23;
- vcpkg;
- WSL;
- настроенный SSH-доступ к Linux-серверу.

Для серверного запуска потребуются:

- Docker;
- клиент SQLite для первоначальной настройки базы данных.

### Клонирование репозитория

```bash
git clone https://github.com/Flacicz/ClashBot.git
cd ClashBot
```

### Конфигурация

Создайте в корне проекта файл `config.json`:

```json
{
  "api": {
    "supercell_token": "<CLASH_OF_CLANS_API_TOKEN>",
    "use_tunnel": true,
    "tunnel_base_url": "https://localhost:8080/v1",
    "base_url": "https://api.clashofclans.com/v1"
  },
  "database": {
    "path": "data/database.sqlite",
    "migrations_path": "src/database/migrations"
  },
  "bot": {
    "telegram_token": "<TELEGRAM_BOT_TOKEN>"
  }
}
```

Параметр `use_tunnel` определяет способ подключения к API Clash of Clans:

- `true` — запросы отправляются через SSH-туннель;
- `false` — используется прямое подключение через `base_url`.

> Файл `config.json` содержит секретные токены и не должен добавляться в Git.

### Получение идентификатора Telegram-чата

1. Добавьте Telegram-бота в нужный чат.
2. Отправьте в чат сообщение или команду для бота.
3. Выполните запрос к методу [`getUpdates`](https://core.telegram.org/bots/api#getupdates):

```text
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/getUpdates
```

4. Найдите в полученном JSON объект `chat` и его поле `id`:

```json
{
  "message": {
    "chat": {
      "id": -1000000000000
    }
  }
}
```

Значение поля `id` является идентификатором Telegram-чата.

> Не публикуйте адрес запроса с настоящим токеном Telegram-бота.

### Локальная сборка на Windows

Установите необходимые библиотеки через vcpkg:

```powershell
vcpkg install curl:x64-windows sqlite3:x64-windows nlohmann-json:x64-windows
```

Укажите путь к установленному vcpkg:

```powershell
$env:VCPKG_ROOT = "C:\path\to\vcpkg"
```

Перед первым локальным запуском создайте каталоги для базы данных и журналов:

```powershell
New-Item -ItemType Directory -Force data, logs
```

Настройте `scripts/startTunnel.sh`, указав адрес Linux-сервера и пользователя для SSH-подключения.

Запустите SSH-туннель через WSL:

```powershell
wsl bash ./scripts/startTunnel.sh
```

Для локального запуска в `config.json` должен быть включён туннель:

```json
"use_tunnel": true
```

Сконфигурируйте проект, передав CMake файл интеграции vcpkg:

```powershell
cmake -S . -B build `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake"
```

Соберите проект:

```powershell
cmake --build build --config Release
```

При использовании генератора Visual Studio запустите приложение командой:

```powershell
.\build\Release\ClashBot.exe .\config.json
```

При использовании Ninja исполняемый файл может находиться непосредственно в каталоге `build`:

```powershell
.\build\ClashBot.exe .\config.json
```

Для остановки приложения нажмите `Ctrl+C`.

### Развёртывание на Linux-сервере

Из-за ограниченных ресурсов сервера Docker-образ собирается локально, сохраняется в TAR-архив и передаётся на сервер через SCP.

Для серверного запуска измените конфигурацию:

```json
{
  "api": {
    "supercell_token": "<CLASH_OF_CLANS_API_TOKEN>",
    "use_tunnel": false,
    "tunnel_base_url": "https://localhost:8080/v1",
    "base_url": "https://api.clashofclans.com/v1"
  },
  "database": {
    "path": "/app/data/database.sqlite",
    "migrations_path": "/app/migrations"
  },
  "bot": {
    "telegram_token": "<TELEGRAM_BOT_TOKEN>"
  }
}
```

Соберите Docker-образ на локальной машине:

```powershell
docker build -t clashbot:latest .
```

Сохраните образ в TAR-архив:

```powershell
docker save -o clashbot.tar clashbot:latest
```

Подготовьте каталоги на сервере:

```bash
ssh <SSH_USER>@<SERVER_IP> "mkdir -p ~/clashbot/data ~/clashbot/logs"
```

Передайте образ и конфигурацию:

```powershell
scp .\clashbot.tar <SSH_USER>@<SERVER_IP>:~/clashbot/
scp .\config.json <SSH_USER>@<SERVER_IP>:~/clashbot/config.json
```

Подключитесь к серверу:

```bash
ssh <SSH_USER>@<SERVER_IP>
```

Загрузите Docker-образ:

```bash
docker load -i ~/clashbot/clashbot.tar
```

Запустите контейнер:

```bash
docker run -d \
  --name clashbot \
  --restart unless-stopped \
  -v "$HOME/clashbot/config.json:/app/config.json:ro" \
  -v "$HOME/clashbot/data:/app/data" \
  -v "$HOME/clashbot/logs:/app/logs" \
  clashbot:latest
```

SQL-миграции уже находятся внутри Docker-образа и применяются автоматически при запуске приложения.

Проверить состояние контейнера можно командой:

```bash
docker ps
```

Для просмотра журналов контейнера используйте:

```bash
docker logs clashbot
```

### Добавление клана и Telegram-чата

После первого запуска ClashBot автоматически создаст базу данных и применит миграции.

Перед ручным изменением базы данных остановите локальное приложение или Docker-контейнер:

```bash
docker stop clashbot
```

Откройте созданную базу данных:

```bash
sqlite3 ~/clashbot/data/database.sqlite
```

Добавьте отслеживаемый клан:

```sql
INSERT INTO clans (tag, name)
VALUES ('#CLAN_TAG', 'Clan name');
```

Добавьте Telegram-чат:

```sql
INSERT INTO telegram_chats (chat_id, title)
VALUES (-1000000000000, 'Telegram chat name');
```

Свяжите клан с Telegram-чатом:

```sql
INSERT INTO clan_subscriptions (clan_tag, chat_id)
VALUES ('#CLAN_TAG', -1000000000000);
```

Выйдите из SQLite:

```sql
.quit
```

Снова запустите контейнер:

```bash
docker start clashbot
```

При локальной разработке запустите приложение повторно обычной командой.

Список отслеживаемых кланов загружается при запуске ClashBot. Во время первого цикла синхронизации сервис получит остальные сведения о добавленном клане через API Clash of Clans.

## Ограничения

- Управление кланами и Telegram-подписками выполняется вручную через SQLite.
- Критерии выявления нарушений пока нельзя настраивать отдельно для каждого клана.
- Telegram используется только для отправки уведомлений — команды управления пока не реализованы.
- В отчётах задействована только часть собираемых данных.
